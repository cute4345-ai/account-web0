# 保留原深色青藍畫面修正版 v0.4.1

這個版本修正上一包帶入舊版畫面的問題。使用者端改用原三端模擬頁的深色青藍版（懸浮卡片、統計圖、最近交易）；管理員與儲值端重用最初提供的/simulation/admin.html和/simulation/topup.html原始版型。

## 保留的畫面
- 三端主題style.css與原檔完全一致，所有原有SVG素材保留。
- 使用者：原登入左右圖像布局、註冊／找回密碼、首頁統計圖與最近交易、卡片管理、商家收款動畫及結果頁。
- 管理員：原三格統計、使用者表格、三個側欄導覽與懸浮卡片圖，原使用者詳細資料雙欄。系統維護功能放在主內容下方，不改原側欄布局。
- 儲值：原八步進度條、讀卡圖、金額表單、深色確認視窗及大型結果／收據布局。

資料來源已改為v0.4.1後端。移除預設示範帳密提示、模擬插卡按鈕與假成功事件；真正讀卡、餘額、審核及交易結果仍以後端為準。管理員需要登入，儲值端免登入。讀卡程式仍使用前一版已完成的自動派單程式，不用更改Applet或貼任務碼。

## 上傳方法
請使用「保留原深色畫面_三端API最終版_v0.4.1.zip」，不要再使用前一個「三端自動派單_v0.4.1_網頁上傳包.zip」。

解壓縮後，把裡面的檔案、assets與simulation資料夾上傳到cute4345-ai/account-web0根目錄，覆蓋同名檔案，保留資料夾結構。不直接上傳ZIP，不只替換app.js。使用者端新增api-client.js、user-live.js、live.css，這些檔案也必須上傳。

三個網址保持：
- 使用者：https://cute4345-ai.github.io/account-web0/
- 管理員：https://cute4345-ai.github.io/account-web0/simulation/admin.html
- 儲值：https://cute4345-ai.github.io/account-web0/simulation/topup.html

Actions最新部署綠勾後，各頁Ctrl+F5。舊account.css等未再引用的檔案可留著，不影響新畫面。

API仍為https://ips-totals-custom-feature.trycloudflare.com/api/v1。管理員第一次需後端授權ADMIN，並登記工作站、將一次性STATION_API_TOKEN填入讀卡電腦。本次不改角色、不註銷卡、不增加實際餘額。
